Safety

  • Hold a fist for about a second to pause or resume (you can change this below).
  • Ctrl + Alt + P pauses from the keyboard, Ctrl + Alt + Q quits.
  • If your hand leaves the camera while dragging, the mouse button is released.

Hand controls

Always on while Airpane runs

Gesture rules

When you make a gesture, Airpane does the action. Each gesture has one job, so gestures already in use are greyed out. Hold = how long to keep the pose still. Repeat = keep firing while held. Cooldown = wait before it can fire again.
